# Skud Pai Sho — historical Gen4 experiment

This branch preserves the historical CPU Micro Gen4 model and a compatible
trainer. Gen3.5 remains the main release; this is research, not an asserted
stronger successor. See [Gen4 instructions](experimental/gen4/README.md).

[Local checks and limitations](docs/VALIDATION.md). The Gen3.1–3.5 compatibility
tools, optional Apple code and data manifests remain available.

[Try the game on the public website](https://gaeldauchy.com/pai-sho/).
